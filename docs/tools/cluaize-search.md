# The `web-search` plugin

**Status: does not run.** The package is a native library, and the Engine cannot run those yet. See [Build types](../plugins/build-types.md#native-binary-binary).

For web access today, use the `fetch` MCP server, which needs `uv`:

```bash
cluaiz mcp install fetch
```

Older versions of this page called it `cluaiz-search` and showed CEL commands. Neither is correct.
